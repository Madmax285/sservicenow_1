# Security

## Access Model

The project requires appropriate access for:

- Requesters
- Approvers
- Network Team members
- Administrators / Developers

## Security Components

The implementation may use ServiceNow roles, groups, ACLs, and catalog user criteria where required by the project requirements.

Security rules will be documented only after they are actually configured and tested in the ServiceNow instance.

## Validation

Security testing will verify that each persona can perform its intended actions and cannot access functionality outside its assigned permissions.
