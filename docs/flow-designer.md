# Flow Designer

## Network Request Automation

The intended automation lifecycle is:

1. A requester submits the Network Request catalog item.
2. The request is validated.
3. Approval routing is determined from the request requirements.
4. The approver receives an approval request/notification.
5. A rejection notifies the requester and ends the approval path.
6. An approval initiates fulfillment for the Network Team.
7. Fulfillment work is tracked until completion.
8. Request status and requester notifications are updated at key stages.

The exact triggers, actions, conditions, and data pills will be recorded here after implementation and testing in ServiceNow.
